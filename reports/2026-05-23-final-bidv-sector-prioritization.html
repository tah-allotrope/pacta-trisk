BIDV Sector Prioritization Module

A reusable scoring module that ranks Decision 263 sectors (thermal power, cement, steel) by composite transition risk, combining PACTA alignment gaps, TRISK stress-test scores, and portfolio exposure weights into an auditable priority list.

01 / Executive Summary

Executive Summary

What Was Built

A reusable R script (scripts/sector_prioritization.R) that synthesizes PACTA alignment gaps, TRISK stress-test priority scores, and portfolio exposure data into a ranked sector priority list. The module produces three outputs: a ranking CSV, a detail CSV with traceable score decomposition, and a horizontal stacked bar chart suitable for report embedding.

Key Result

On the MCB synthetic portfolio, Power ranks first (1.000, Critical) across all three dimensions. Steel (0.158, Low) and Cement (0.011, Low) follow but fall well below the Critical threshold. Power's dominance is robust across tested weight variations — confirming that portfolio concentration is the dominant driver of sector priority in this illustrative portfolio.

02 / Background & Objective

Background & Objective

Context. BIDV faces growing regulatory pressure under Decision 263 (Quyết định 263/QĐ-TTg, 2022), which mandates GHG emission quotas for thermal power, steel, and cement facilities. The repo already produces sector-level alignment gaps (via PACTA) and borrower-level stress-test priority scores (via TRISK), but no module existed to combine these independent outputs into a unified, actionable sector ranking.

Objective. Build a transparent, reusable scoring module that answers: "Which Decision 263 sector should BIDV prioritize for climate risk reduction and borrower engagement?" The module must consume only existing pipeline outputs — no re-running of PACTA or TRISK — so it can run quickly as a post-processing step. It must be demonstrated on the synthetic MCB portfolio as an illustrative example, with explicit placeholders for substituting real BIDV data.

Scope. Strictly the three Decision 263 sectors (thermal power, cement, steel). Automotive is excluded — it is not a Decision 263 sector. Borrower-level engagement scoring (GAP-07) is deferred; this module operates at the sector level.

05 / Methodology

Methodology

Three scoring dimensions. Each Decision 263 sector is scored across three dimensions, each normalized to [0, 1] via min-max scaling across sectors:

  1. Alignment gap severity: For power (market-share sector), use the maximum positive percentage-point gap above target across high-carbon technologies. For cement and steel (SDA sectors), use the emission intensity percentage gap vs. 2030 target.
  2. Transition stress severity: Aggregate TRISK borrower-level priority scores within each sector using exposure-weighted mean. Higher values = more stress concentrated in larger borrowers.
  3. Portfolio exposure concentration: Each sector's share of total Decision 263-relevant portfolio exposure (VND). Higher share = more concentrated = higher priority.

Composite score formula:

composite = 0.35 × alignment_score + 0.35 × stress_score + 0.30 × exposure_score

Priority bands: Critical (≥0.70), High (0.50–0.69), Medium (0.30–0.49), Low (<0.30).

Configurability: All three weights accept CLI overrides. The script also supports a standalone weight-sensitivity mode that tests alternative weight combinations and reports ranking stability.

Interpretation

Power is the unequivocal priority sector (1.000 Critical). Three converging factors drive this: (1) power's coal capacity is 13.4 percentage points above the PDP8 target — the largest misalignment across all sectors; (2) the power sector has 13 TRISK-stressed borrowers including three coal-heavy names with priority scores of 95–100; (3) power accounts for 81.8% of total Decision 263 exposure.

Steel ranks second (0.158 Low) despite having only two borrowers — its SDA alignment gap (7.2% above 2030 target) is significantly higher than cement's (2.1%). However, stress and exposure scores are both near zero, limiting the composite.

Cement ranks last (0.011 Low) with the smallest alignment gap (2.1%) and low exposure share (10.4%).

Sensitivity

When weights shift toward alignment (0.50) and away from stress/exposure (0.25 each), steel's score increases by 43% (0.158 → 0.226) — reflecting its moderate alignment gap. The ranking order is stable across all tested weight combinations, confirming power's dominance is robust to reasonable weight variations.

08 / Implementation Path

Implementation Path

1. Run with Real BIDV Data

Replace data/vietnam_loanbook.csv with BIDV's normalized loanbook. Re-run scripts/sector_prioritization.R to produce BIDV-specific ranking. The script accepts CLI flags for custom weights: --w-alignment 0.40 --w-stress 0.40 --w-exposure 0.20.

2. Embed in Report Generator

The ranking CSV, detail CSV, and chart are already consumed by scripts/generate_bidv_report.R (GAP-04). Update the report by re-running the generator after a BIDV-specific prioritization run.

3. Calibrate Weights with BIDV Risk Team

Use the weight-sensitivity mode to test how different weight preferences affect the ranking. BIDV's risk appetite (e.g., more weight on exposure vs. alignment) can be reflected through weight calibration, not code changes.

4. Defer to GAP-07 (Engagement Scoring)

The sector-level prioritization feeds into borrower-level engagement scoring. The highest-priority sector (Power) should be the first target for borrower-level scoring and action planning.

09 / Risks / Open Questions

Risks / Open Questions

Risks

  • Steel match coverage ~4%: Low ABCD matching makes steel's alignment and stress results unreliable. Steel's true priority may be higher.
  • TRISK floor values: Cement and steel both scored the floor stress value (100), limiting differentiation. This is a synthetic data artifact — real TRISK scores would vary more across sectors.
  • Power dominates via exposure: Power's 81.8% exposure share drives its Critical score. A more balanced portfolio would produce a more nuanced ranking.

Open Questions

  • Weight calibration: Should BIDV's risk appetite favor alignment gap (SBTi-style) or stress severity (credit-risk-style)?
  • Automotive: If BIDV has material auto exposure, should the scope expand beyond Decision 263?
  • TRISK for cement/steel: Current TRISK is sector-context only; borrower-level SDA implementation would improve stress differentiation.
