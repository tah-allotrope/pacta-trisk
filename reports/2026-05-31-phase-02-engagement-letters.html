03 / Math / Algorithm Used

Math / Algorithm Used

No statistical math in this phase — the algorithm is a safe render pipeline:

  • Token substitution: fixed-string (non-regex) replacement of {{key}} for every key in a complete map, so no value can accidentally be re-interpreted as a token.
  • Nesting avoidance: prompt prose (which itself contains {{borrower}}, {{alignment_gap}}) is pre-substituted, then injected, so the final template pass never meets a nested token.
  • Residual-token guard (RISK-02-01): after rendering, regmatches(letter, gregexpr("\\{\\{[^{}]+\\}\\}", letter)) must return empty; any hit aborts the run naming the borrower and offending token.
  • Figure formatting: NPV as %+.1f%% of baseline, PD as %+.1f pp, market-share gap as pp vs PDP8, SDA gap as % above pathway; NA TRISK fields render as an explicit "Not assessed" sentence rather than a blank.

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • English-primary, not fully bilingual: per Q-002, letters keep Vietnamese key terms inline but drop the full side-by-side Vietnamese block. A bank wanting a Vietnamese-first version would expand the template and prompt CSV — no code change needed.
  • Covenant/engagement wording is illustrative: the three actions per sector are demo language; a real deployment needs legal review (the disclaimer says exactly this).
  • Second-best alternative (rejected): native DOCX via the officer package (the original Idea 3 suggestion). Deferred for v1 to avoid a new dependency and Windows rendering risk (ALT-001); print-to-PDF from HTML matches the repo's existing deliverable pattern.
  • Top-N only: default N=10; a bank wanting all borrowers or a hand-picked subset would extend the selection step (seeded for PHASE-04 controls).
07 / Errors / Warnings / Flags

Errors / Warnings / Flags Encountered

  • Caught & fixed: the first run aborted (exit 1) because the residual-token guard found a literal {{tokens}} inside the template's own CSS comment. Reworded the comment to brace-free documentation; re-run produced all 10 letters clean. This is the guard working as designed, not a defect.
  • No R warnings on the clean run. Pre-flight aborts non-zero if the priority CSV or a sector's prompt row is missing.
  • Verified the editable path: adding a marker to the power prompt row changed the rendered letter on re-run; reverting removed it.
