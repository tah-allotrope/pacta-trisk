# Archived deck variants

`bank_prospect_deck_v2.pptx` (in `present/`, built by `build_deck_v2.py`) is the
canonical bank-prospect deck: it fixed the template-mode issues present in the
original build and is the version referenced by the pilot conversion pack
(`pilot/`) and session scripts.

This folder holds earlier/alternate builds kept for reference only:

- `bank_prospect_deck_original.pptx` / `build_deck_original.py` / `add_speaker_notes_original.py` /
  `render_original/` — the first working build, superseded by v2's template-mode fix.
- `bank_prospect_deck_claude.pptx` / `build_deck_claude.py` / `render_claude/` — an
  alternate build produced with the `/present` skill, kept for side-by-side comparison.

Do not present from these files to a prospect; use `present/bank_prospect_deck_v2.pptx`.
