# Pilot Conversion Pack

Materials for converting a bank-prospect demo (synthetic MCB data) into a
signed, paid real-data engagement. Everything here is bank-agnostic with
`{{BANK_NAME}}`-style tailoring slots — follow `tailoring_checklist.md` to
customize a copy for a specific prospect in under an hour.

## Contents

| File | Purpose |
|---|---|
| `loanbook_data_spec.md` | "Your data here" sheet — what a bank needs to send for a real-data phase. |
| `real_data_phase_proposal.md` | Scoped next-phase engagement proposal template. |
| `tailoring_checklist.md` | Steps to customize the pack for one named bank. |
| `intake_demo_script.md` | Click-path script for demoing the Intake Wizard live. |
| `session_scripts.md` | Talk tracks for the 2-3 guided pilot sessions. |
| `vn_glossary.md` | PACTA/TRISK/credit-risk Vietnamese terminology glossary. |
| `vn/` | Vietnamese reference translations (draft quality, English prevails). |
| `rendered/` | Client-shareable HTML renders of the English documents. |
| `rendered/vn/` | Client-shareable HTML renders of the Vietnamese documents. |

All materials describe a **synthetic-data pilot**: every number in the demo
comes from the fictional Mekong Commercial Bank (MCB) case, not the
prospect's own book. Say so explicitly wherever a document could be
mistaken for a real assessment.
