## 1. Context

{{BANK_NAME}} has evaluated the PACTA + TRISK Vietnam platform using a
synthetic bank case (Mekong Commercial Bank). This proposal scopes the next
phase: running the same PACTA alignment and TRISK transition-risk stress
test against {{BANK_NAME}}'s own loanbook.

## 2. Scope

- **Intake:** {{BANK_NAME}} provides a loanbook extract per
  `loanbook_data_spec.md`. Anonymization approach: {{ANONYMIZATION_APPROACH}}.
- **Validation:** automated schema validation and sector mapping, with a
  validation report returned to {{BANK_NAME}} before analysis proceeds.
- **PACTA alignment:** portfolio alignment against PDP8, NDC 2022, and IEA
  NZE pathways, covering sectors: {{SECTOR_LIST}}.
- **TRISK stress test:** borrower/sector-level NPV and probability-of-default
  stress under {{SCENARIO_SELECTION}} (default: shock year 2030, base
  discount/risk-free/passthrough assumptions — adjustable via the Scenario
  Builder).
- **Outputs:** engagement priority scoring, engagement letter drafts, and a
  Decision 263 / TCFD-aligned disclosure pack.
- **Delivery:** private dashboard instance scoped to {{BANK_NAME}}'s data,
  plus a findings report ({{REPORT_LANGUAGE}}).

## 3. Out of scope for this phase

- New sectors beyond {{SECTOR_LIST}}.
- Methodology changes (e.g., borrower-level SDA for cement/steel).
- Integration with {{BANK_NAME}}'s internal systems (delivery is file-based).
